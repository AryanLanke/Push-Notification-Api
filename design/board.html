Stop dressing the console up.
Make it read like an instrument.

Both dashboards move to one system: warm paper, a near-black rail, hairline rules instead of floating cards, one burnt accent, and monospace for every number, status and identifier. Dense where the data is dense, quiet where the device is quiet. No gradients, no shadows, no emoji, no italic serif.

The replacement rule: every visual choice carries information — a rule separates, a mark signals state, colour is reserved for urgency, and size ranks importance. If it only makes the page “look designed”, it goes.

04

Rules

hard constraints — keep these when it becomes code

Radius 2px, nothing round

Inputs, chips, buttons and panels share one radius. No pills, no 8px cards.

2PX — IN SYSTEM PILL

Borders, not shadows

Hierarchy comes from hairlines and the paper/surface step. The only shadow allowed is a drawer overlay.

1PX #E2E0D6 ELEVATION

Colour is a signal

Ink for everything. Burnt only for the primary action and the freshest event. Green/amber/red only for state.

ok warn fail idle

Icons: 1.3px stroke, 15px

Hand-picked line icons that inherit colour. Never emoji, never filled glyphs.

Motion: 120ms, state only

Hover tints, the live square breathes, a new row settles once. No lifts, no slides on hover.

liveopacity 1 → .25 → 1

Spacing: 4 / 8 / 12 / 16 / 22 / 28

Panel padding 16. Page padding 28. Gaps 16. Nothing in between — the rhythm is what makes it feel deliberate.

Before this becomes code

decisions + states to lock
01Keep the light canvas + dark rail, or invert to a full dark console? Light-on-warm-paper is the recommendation: it survives screenshots, print and projectors.
02Product name. The mockups say “relay”; the repo says Producer / Consumer. Pick one and use it in both titles.
03Empty, loading and error states for: queue, history, device list, SSE dropped, push denied.
04Keyboard: ⌘K search, J/K to move down the live-jobs table, Enter to open a job.
05Tables need sorting + a sticky header once history exceeds one screen.
06Decide whether the consumer gets a channel filter or stays a pure stream. A filter implies devices can subscribe to several topics.
